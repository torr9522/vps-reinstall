# VPS Reinstall

Menu frontend for the vendored `bin456789/reinstall` engine.

Run:

```bash
bash vps-reinstall.sh
```

The menu dispatches to:

```text
vps-reinstall/reinstall.sh
```

Default install password:

```text
Dx@Debian.dx
```

This repository vendors the script layer. It does not include Debian, Ubuntu, or
Windows OS images, package repositories, Windows ISO files, or cloud-provider
driver archives.
