# Dependency List

This branch vendors the `bin456789/reinstall` script layer under:

```text
/vps-reinstall/
```

The root launcher is:

```text
/vps-reinstall.sh
```

## Scope

The repository localizes the script/control-plane resources needed by the
launcher and the vendored reinstall engine.

Per operator decision, Debian, Ubuntu, and Windows operating-system payloads are
not stored in this repository. That means OS netboot files, ISO files, package
repositories, cloud images, and Windows driver archives remain runtime upstream
dependencies of the underlying installer.

This repository is therefore self-contained for the menu and vendored script
resources, but it is not an offline mirror of Debian, Ubuntu, Windows, Microsoft
ISO content, Linux package repositories, or cloud-provider driver archives.

## Runtime Upstream Dependencies Not Localized

These remain external because Debian/Ubuntu/Windows payloads are not included in
this repository.

### Debian

- Debian netboot kernel/initrd from configured Debian mirrors.
- Debian installer udebs and package repositories.
- Debian firmware cpio when firmware mode is used.
- Debian ELTS/Freexian repositories for old releases when selected.

Typical domains generated by `vps-reinstall/reinstall.sh`:

```text
deb.debian.org
archive.debian.org
cdimage.debian.org
deb.freexian.com
mirror.nju.edu.cn
```

### Ubuntu

- Ubuntu release ISO or cloud image.
- Ubuntu package repositories used during installation/customization.

Typical domains generated by `vps-reinstall/reinstall.sh` and
`vps-reinstall/trans.sh`:

```text
releases.ubuntu.com
cdimage.ubuntu.com
cloud-images.ubuntu.com
archive.ubuntu.com
security.ubuntu.com
mirror.nju.edu.cn
```

### Windows

- Windows ISO link discovery pages and/or manually supplied ISO URLs.
- Windows ISO payloads.
- Public-cloud Windows drivers and VirtIO drivers.
- Microsoft/Intel/cloud-vendor driver sources when matching hardware requires
  them.

Typical runtime domains:

```text
massgrave.dev
software.download.prss.microsoft.com
download.microsoft.com
fedorapeople.org
s3.amazonaws.com
s3.cn-north-1.amazonaws.com.cn
xenbits.xenproject.org
downloadmirror.intel.com
mirrors.tencent.com
ecs-instance-driver.obs.cn-north-1.myhuaweicloud.com
windows-driver-*.oss-*.aliyuncs.com
storage.googleapis.com
packages.cloud.google.com
aka.ms
```

### Alpine Runtime Environment

The underlying installer uses Alpine as an intermediate environment for many
flows, so APK repositories remain runtime dependencies unless a complete Alpine
package mirror is provided separately.

Typical domains:

```text
dl-cdn.alpinelinux.org
mirror.nju.edu.cn
```

### Optional frpc

If frpc tunneling is enabled, the engine may query/download frp release assets.

Typical domains:

```text
github.com/fatedier/frp
mirrors.nju.edu.cn/github-release/fatedier/frp
files.m.daocloud.io/github.com/fatedier/frp
```

## Important Limitation

No branch in this repository contains Debian/Ubuntu package mirrors, Debian
installer mirrors, Ubuntu ISO/cloud-image mirrors, Windows ISO files, Microsoft
download assets, or cloud-provider Windows drivers. Therefore, a full offline
install is not achievable from this repository alone.
